# Application Spring and Postgres

This application provides the sample api rest using spring framework and postgres database

## Requisities

[x] Java 17
[x] Postgres Database 17

## Technologies

[x] Docker
[x] Spring Framework
[x] OpenAPI (springdoc, Swagger UI and ReDoc)

## Design

[x] Clean Architecture


## API Documentation (OpenAPI)

With the application running (default port `8080`):

| Interface  | URL                                    |
|------------|----------------------------------------|
| Swagger UI | http://localhost:8080/swagger-ui.html  |
| ReDoc      | http://localhost:8080/redoc.html       |
| OpenAPI spec (JSON) | http://localhost:8080/v3/api-docs |
